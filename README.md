# IVR Tech Solutions - Internship Offer Letter Generator & Admin Suite

Official corporate document automation suite for **IVR Tech Solutions Private Limited**.

## Features
- **Sequential Offer Letter Generation**: Generates automated sequential reference IDs (e.g., `IVR/2026/FEB/INT-001`).
- **Google Forms Sync**: Real-time integration with Google Sheets / Google Forms application responses.
- **Direct PDF & DOCX Export**: Clean, high-resolution document generation with authorized signature and corporate branding.
- **Zoho & SMTP Email Automation**: Send candidate offer letters directly to candidate email inboxes with HTML email templates.
- **Strict Compliance**:
  - Zero company seal / stamp on all letters.
  - Authorized Signatory: Indla venkata Gowtham Kumar Reddy (Managing Director).
  - Optional unconfirmed address handling (hidden when unconfigured).

npm install
